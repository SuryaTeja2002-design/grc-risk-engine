# 🚀 GRC Risk Engine

A fully interactive **AI-powered GRC risk assessment tool** built in vanilla JavaScript — no frameworks, no backend, no dependencies except Chart.js and SheetJS.

Works 100% offline. Just open the file.

---

## ✨ Features

🤖 **AI-powered risk suggestions**  
Type your company type and get auto-generated risks using Claude API

📊 **Animated threat dashboard**  
Dynamic risk visualizations with heatmaps and smooth UI animations

🔴 **Real-time risk scoring engine**  
Change one input → recalculates everything instantly across the app

📈 **Trend analysis (NIST-based)**  
Identify which NIST functions are most exposed

🎯 **AI remediation generator**  
Click a risk → get intelligent remediation steps instantly

💾 **Save & Load sessions**  
Persist your risk register locally

🖨️ **PDF-quality reporting**  
Generate clean, printable reports (not just raw HTML)

🌐 **Multi-tab dashboard**
- Risk Register  
- Risk Matrix  
- NIST Analysis  
- Reports  

---

## 🛠 Tech Stack

- Vanilla JavaScript (no frameworks)
- Chart.js
- SheetJS (Excel export)
- CSS Grid + Flexbox
- Claude API (AI features)

## 🚀 How to Use

1. Download or clone the repo
2. Open `index.html` in your browser
3. Enter your company type
4. Add risks or generate them using AI
5. Analyze using dashboard + matrix
6. Generate reports or export to Excel
